# Tau Ceti Labs Website

Standalone Astro/Azure Static Web Apps company hub for Tau Ceti Labs.

Canonical public destination: `https://taucetilabs.com/`.

## Commands

```powershell
npm install
npm run check
npm run build
npm run verify:static
npm run test:api
```

## Purpose

This site is the company hub. It routes visitors to LithoBreak, RaceCards, Discord, press, legal, and contact surfaces. Product details live on the standalone product sites.

The future game room is intentionally documented as Phase 2 and is not launch scope.
